# Authenticated Diffie-Hellman Key Exchange Project

This project implements an authenticated finite-field Diffie-Hellman key exchange with library prime generation, manual square-and-multiply modular exponentiation, trial-division factorization, generator verification, and Ed25519 identity key signatures.
